# Optional handout

[Build me a read-only X connector](x_readonly_connector_for_agents.md) is an optional, paid,
**macOS-only** extension. It is not required for participation. Public-post retrieval is the default;
access to your own bookmarks is a separate opt-in.

This is the existing self-contained student guide prepared on 13 August 2026, copied without
changing its embedded scripts or source hashes. It contains an agent-led setup brief, checks and
rollback instructions. Read its scope before asking an agent to apply it. This pack does not install
or test a live connector, and does not include account details or credentials.

The guide's pinned versions, tool catalogue and service details are dated. Review them against
current official documentation before a live setup session; do not silently substitute versions
inside its verified script bundle. The [connection exercise](../exercises/01-connect-tools/README.md)
does not require purchasing X API access.
